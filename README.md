# 宿舍管理系统

## 项目背景

为了更好地管理学校宿舍资源和提升管理效率，需要设计⼀个宿舍管理系统。该系统旨在简化和优化宿舍的⽇常管理流程，包括宿舍的分配、学⽣的⼊住和退宿操作，以及对宿舍信息的查询等。通过建⽴⼀个统⼀的管理平台，可以有效减少⼈⼯操作带来的复杂性，提⾼宿舍资源的利⽤率，同时为学⽣提供更加便捷的服务。系统的引⼊不仅能使管理更加规范和透明，还能及时满⾜学⽣的住宿需求，进⽽提升学校整体的管理⽔平和服务质量。

## 模块

1. **⽤户管理⽤户注册**：学⽣可以注册新账户，输⼊学号、姓名、密码和联系⽅式等；
   - 提⽰：该功能可以通过⽂件操作来将⽤户输⼊的信息写⼊⼀个⽂件中，这样就可以完成最初始数据的持久化。
2. **⽤户登录**：学⽣通过学号和密码登录系统；
   - 提⽰：将学⽣的信息与库内的信息对⽐即可。
3. **管理员权限**：管理员⽤户（初始⽤户名和密码由系统设定）拥有更多权限，如分配宿舍、查询所有学⽣信息等；
   - 提⽰：管理员与学⽣两种⾓⾊登录后的界⾯应该不⼀样，管理员能有的操作应该更多。
4. **宿舍管理宿舍**：管理员可以对宿舍进⾏管理。

   - 管理员可以添加新的宿舍楼和宿舍房间，包括宿舍楼的名称、位置、房间数量以及每个房间的床位数量；
   - 删除宿舍：管理员可以删除宿舍楼或宿舍房间（如果房间内有学⽣⼊住，应提⽰管理员先处理这些学⽣的退宿）；
   - 更新宿舍信息：管理员可以更新宿舍楼或宿舍房间的信息，如房间状态（空闲/已分配）、维修记录等。

5. **⼊住与退宿管理**：管理员可以为学⽣分配宿舍房间。
   - ⼊住管理：系统应检查房间是否空闲，并更新房间状态和⼊住记录。
   - ⼊住确认：学⽣登录后，可以查看⾃⼰的宿舍分配情况，并进⾏⼊住确认（可选功能，⽤于确认学⽣已实际⼊住）。
   - 退宿申请：学⽣可以提交退宿申请，系统应记录申请时间并通知管员。
   - 审核退宿：管理员审核学⽣的退宿申请，如果批准，则更新房间状态和退宿记录。
6. **查询功能学⽣查询**：学⽣可以查询⾃⼰的宿舍信息、⼊住记录和退宿申请状态。
7. **管理员查询**：管理员可以查询所有学⽣的宿舍信息、⼊住记录和退宿记录，以及宿舍楼和房间的使⽤情况。
   - 学⽣的每⼀条⼊住信息都应该记录下来，⽅便后续查找。
8. **界⾯设计使⽤控制台界⾯（命令⾏）实现系统交互**。
9. **设计清晰的菜单和提⽰信息，⽅便⽤户操作**。
   以上功能是必须实现的，当然功能的细节可以由⾃⼰的实现思考，⽐如登录后学⽣的界⾯应该的怎么样的、宿舍应该⽤什么数据结构进⾏分配等等。我们⿎励同学们在基础功能上进⾏⾃由扩展（加分项），不过保持宁缺⽏滥的原则，添加的功能在演⽰的时候不能出现 bug，否则可能会成为减分项。

## 扩展功能示例

1. **通知与提醒系统**。
   - 消息通知：系统可以集成消息通知功能，通过邮件、短信或系统内部通知的⽅式提醒学⽣宿舍分配结果、⼊住确认、退宿申请进度等信息。
   - 到期提醒：管理员可以设置租期到期提醒或宿舍检查提醒，系统会在指定时间⾃动发送通知给学⽣或管理员。
2. **统计与报表⽣成**。
   - 宿舍使用统计：提供宿舍使⽤率、⼊住率、退宿率等数据统计功能，⽣成详细的报表；
   - 月度//年度报表：系统可以⽣成按⽉或年度的宿舍使⽤情况报表，分析宿舍资源的利⽤率和空置情况。
3. **维修与报修管理**。
   - 报修申请：学⽣可以在系统中提交宿舍设施的维修申请，系统记录报修时间和详情，并将信息转发给管理员。
   - 维修记录：管理员可以查看维修记录，包括维修时间、处理状态和维修结果，并更新房间的维护状态。

## 技术要求

1. 需要使⽤ C++语⾔进⾏开发；
2. ⾯向对象编程：合理设计类与对象，使⽤继承、多态等特性。
3. 数据结构：使⽤合适的数据结构存储⽤户信息、宿舍信息和⼊住/退宿记录。
4. ⽂件操作：实现数据的读写操作，确保数据的持久化。
5. 异常处理：对可能的异常情况（如⽂件读写错误、输⼊错误等）进⾏处理。
6. 代码规范：遵循良好的编程规范，包括命名规范、注释规范等。

## 提交要求

1. **源代码**：提交完整的 C++源代码，包括所有类和函数的实现。
2. **设计报告**：撰写⼀份设计报告，介绍系统的设计思路、类图、主要算法和数据结构等。
